# 资源中心

后台“资源中心”（`/admin/resource-center`）与“数据源管理”（`/admin/sources`）采用卡片式界面。

- 候选目录在 `server/src/resource-catalog.ts`，随源码发布，不写入数据库，也不会在启动、查看或检测时自动导入。
- 点击资源名称或“资源站官网”打开目录中审核过的官网。接口地址只是数据读取入口，不作为官网地址推测依据。
- 点击“上架”才创建或启用数据库中的 Source；数据源管理只展示启用的源。
- 上架不执行采集、不改变首页默认源、不添加会员或源分组授权。会员仍须拥有相应观看权限。
- 下架只将 Source.enabled 改为 false。已采集影片、分类绑定、搜索开关和会员授权保留，再上架时恢复使用。
- 上架状态需要持久化，沿用部署时选择的数据库；候选目录本身不依赖数据库存储。没有新增数据库表或迁移。
- 接口检查只检查影片/分类数据可读取，不保证全部播放地址有效。目录不是版权授权，使用内容前需自行确认授权范围。

扩充目录时，在源码数组中添加独立的 key、名称、HTTPS 官网、公开接口、说明与标签；不要放私有订阅地址、密码或令牌。变更后重新构建并重启。接口变更不会覆盖同名但不同接口的现有源；遇到冲突需管理员先确认。不会下载或执行第三方播放器脚本。

当前包含非凡资源候选项。条目数量、域名和可用性会随站方变化，不宣称永久可用或覆盖全部影视。
